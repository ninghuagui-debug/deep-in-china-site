📝 Free SRT Subtitle Toolkit

Four local-only batch tools for subtitle files — shift time axis, merge multiple SRT, split long captions, extract plain text. Everything runs in your browser; your files are never uploaded.

1 · Shift Time Axis

Add or subtract a fixed number of seconds to every timestamp. Use when audio and subtitle drift apart. Negative values that push start below 0 are clamped to 00:00:00,000.
Offset (sec)

2 · Merge Multiple SRT

Select two or more .srt files (processed top-to-bottom in the order you pick them). Each file's timeline is auto-continued after the previous one ends, with an optional gap between parts.
Gap (sec)

3 · Split Long Captions by Duration

Break any caption longer than the max duration into evenly-timed shorter lines (text is split proportionally, breaking at spaces when possible). Great for readability on fast-paced shorts.
Max dur (sec)

4 · SRT → Plain Text

Strip all timing and indices, keep only the caption text. Join captions with a blank line (or a space) for transcripts / copy-paste.
